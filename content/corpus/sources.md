# Practice texts

Recall, reviews, Endless and Quick practice draw their sentences from here, so a
skill is practised on text you haven't seen before. Learn keeps the written texts
of each lesson, which are about their own keys.

- `prose.txt`: sentences and clauses from two public-domain books, via Project
  Gutenberg: Edward Sapir, *Language: An Introduction to the Study of Speech*
  (1921, ebook 12629), and Otto Jespersen, *Language: Its Nature, Development
  and Origin* (1922, ebook 53038). `extract.py` keeps lines of plain words
  (letters, spaces, commas), 14 to 70 characters long, so every word is a Vim
  word and every line fits the practice box.
- `terms.txt`: linguistics terms, written for this project. Code tasks build
  their names from them (`split_morpheme(stem, suffix)`).
